# Daniel Bitengo

I build developer tools and ship them in the open. Everything I make runs on your machine: local-first, keyboard-first, no accounts, nothing phones home. I didn't set that as a principle. I just kept building things that way and learned the name for it later. It's cheaper to build, it's faster to use, and the tool stays yours.

**[Reeve](https://github.com/Dancode-188/reeve)**: a terminal cockpit for AI agents. Watch them work, score the work, and step in when a run goes sideways. One Rust binary.

**[SyncKit](https://github.com/Dancode-188/synckit)**: an offline-first sync engine. Fugue and Peritext CRDTs in Rust and WASM, TLA+ models in the repo, thousands of tests across five languages.

**[Graft](https://github.com/Dancode-188/graft)**: a keyboard-first Git GUI on Tauri. Command palette, interactive rebase, visual branch graph. Free, where the alternatives ask $99.

All of it solo, in the open, over the last year. Reeve is the first I mapped out on a whiteboard before writing code. The stack I reach for is Rust, TypeScript, and Python, with TLA+ when correctness is worth proving.

I'm 21, in Nairobi, looking for my first team: infrastructure, developer tools, anywhere the systems are the hard part.
